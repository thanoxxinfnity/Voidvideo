# Training data layout

```
data/
├── raw_clips/       <- Drop your source .mp4 clips here (gitignored, never committed)
├── captions/         <- Optional: <clip_stem>.txt per clip with a hand-written caption
└── processed/        <- Generated by scripts/prepare_dataset.py (gitignored)
    ├── clips/
    ├── metadata.jsonl
    └── dataset-metadata.json
```

## Clip specification

| Spec | Requirement |
|---|---|
| Duration | ~6 seconds (target: 49 frames @ 8fps for CogVideoX-2B). Longer clips are trimmed/sampled automatically. |
| Source frame rate | ≥24fps preferred; resampled down to 8fps by `prepare_dataset.py`. |
| Resolution | ≥720×480 (landscape) or ≥480×720 (portrait) — pick **one** orientation for the whole dataset. |
| Format | `.mp4` (H.264), one continuous shot per file, no scene cuts, no burned-in subtitles/watermarks/logos. |
| Count | Minimum 50, recommended 150–300, ideal 500+. |
| Style | One consistent art style/lineart weight/shading approach across the whole set — this is literally what the LoRA learns. Mixed styles → muddy LoRA. |
| Audio | Irrelevant, stripped automatically. |
| Captions | Optional but recommended. Add `data/captions/<clip_stem>.txt` per clip, or run `prepare_dataset.py --auto-caption` for a BLIP-2 first pass. |

Spread clips across: locomotion (walk/run/idle/turn), gesture (wave/point/reach),
facial (blink/smile/frown/surprise/talk), secondary motion (hair/cloth/physics),
mostly-static camera with a few slow pans, and a mix of close-up/medium/wide framing.

## Building the dataset

```bash
# 1. Drop clips in data/raw_clips/, optionally add captions in data/captions/
python scripts/prepare_dataset.py --task t2v              # or --task i2v
python scripts/prepare_dataset.py --task t2v --auto-caption  # BLIP-2 captions for anything uncaptioned
```

This normalizes every clip to the resolution/fps/frame-count defined in
`configs/training_config.yaml` under the chosen task, and writes
`data/processed/metadata.jsonl`.
